Gestão de Fazenda

Programa de computador para produtores de café: lançamentos do dia, colheita, estoque, contas e relatórios. Os dados ficam no computador do produtor.

Uso do Google Drive

É opcional. Quem conecta a própria conta Google guarda nela, uma vez por dia, uma cópia de segurança dos dados, para poder restaurar se o computador estragar.

O programa usa a permissão drive.file: só vê os arquivos e a pasta que ele mesmo criou.
